# 四、运算符重载与友元

本章目标：练习把对象做成“像值一样使用”的类型。运算符重载应保持直觉一致，不要让 `+`、`<`、`<<` 出现副作用。

## 题 10：复数类

实现 `Complex` 类，支持复数加法和流输出。

### 功能要求

- 保存实部和虚部，类型可使用 `double`。
- 构造函数支持默认值 `0`。
- 重载 `operator+`，返回两个复数的和，不修改左右操作数。
- 重载 `operator<<`，输出格式为 `real + imagi`。
- `operator+` 和输出操作应支持 `const` 对象。

### 演示要求

在 `main()` 中创建：

```cpp
Complex a(1, 2);
Complex b(3, 4);
std::cout << a + b << '\n';
```

基础验收输出：

```text
4 + 6i
```

### 自测建议

- 虚部为 `0`。
- 实部或虚部为负数。
- 链式输出：`std::cout << a << b;`。

## 题 11：分数类

实现 `Fraction` 类，支持约分、加法和比较大小。

### 功能要求

- 构造函数接收分子和分母。
- 分母不能为 `0`；遇到非法分母应抛出 `std::invalid_argument`。
- 构造后始终保持最简形式。
- 负号统一放在分子上，例如 `1/-2` 应归一化为 `-1/2`。
- 支持 `operator+`，返回约分后的新分数。
- 支持 `operator<`，用于比较大小。
- 支持 `operator<<`，输出格式为 `numerator/denominator`。

### 演示要求

在 `main()` 中创建：

```cpp
Fraction a(1, 2);
Fraction b(1, 3);
std::cout << a + b << '\n';
std::cout << (b < a) << '\n';
```

基础验收输出：

```text
5/6
1
```

### 自测建议

- `Fraction(2, 4)` 输出 `1/2`。
- `Fraction(1, -2)` 输出 `-1/2`。
- `Fraction(0, 5)` 输出 `0/1`。
- 大数相乘比较时可能溢出，进阶实现可使用更宽整数类型。
