# 二、构造、析构与资源管理

本章目标：理解对象生命周期、RAII、所有权和拷贝控制。写拥有资源的类时，必须主动说明对象能否拷贝、能否移动、如何销毁。

## 题 4：观察构造和析构顺序

编写一个 `Tracer` 类，构造时输出 `"construct"`，析构时输出 `"destroy"`。在函数内部创建局部对象，观察局部对象的生命周期。

### 功能要求

- `Tracer` 的构造函数输出一行 `construct`。
- `Tracer` 的析构函数输出一行 `destroy`。
- 编写一个测试函数，在函数内部创建局部 `Tracer` 对象。
- 用输出顺序证明局部对象在离开作用域时析构。

### 演示要求

基础验收输出：

```text
before
construct
inside test
destroy
after
```

### 自测建议

- 在嵌套作用域中创建多个对象，观察析构顺序。
- 思考如果构造函数抛异常，析构函数是否会执行。

## 题 5：禁止拷贝的类

设计一个 `NonCopyable` 类，允许默认构造，但禁止拷贝构造和拷贝赋值。

### 功能要求

- 显式保留默认构造函数。
- 使用 `= delete` 禁止拷贝构造。
- 使用 `= delete` 禁止拷贝赋值。
- 本题只做语法检查，不需要 `main()`。

### 自测建议

临时写下列代码，确认编译失败后再删掉：

```cpp
NonCopyable a;
NonCopyable b = a;
```

## 题 6：简单动态数组

实现一个管理动态整型数组的 `IntArray` 类。

### 功能要求

- 构造函数接收数组大小，并分配 `int` 动态数组。
- 所有元素初始化为 `0`。
- 析构函数释放数组，不能内存泄漏。
- 提供非常量和常量版本的 `operator[]`。
- 越界访问应抛出 `std::out_of_range`。
- 提供 `size()` 返回数组长度。
- 禁止拷贝构造和拷贝赋值，避免浅拷贝导致重复释放。

### 演示要求

在 `main()` 中创建长度为 `3` 的数组，设置前两个元素为 `10` 和 `20`，输出它们的和。

基础验收输出：

```text
30
```

### 自测建议

- 访问 `arr[arr.size()]` 应抛异常。
- 构造长度为 `0` 的数组时程序不应崩溃。
- 思考如果要支持拷贝，应实现深拷贝还是禁止拷贝。
