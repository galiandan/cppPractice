# 六、STL 算法与函数对象

本章目标：用标准算法表达意图，练习 lambda、谓词、累加、查找和排序规则。

## 题 16：筛选偶数并求和

给定 `std::vector<int>`，使用 STL 算法筛选偶数并求和。

### 功能要求

- 使用 `std::copy_if`、`std::accumulate` 或等价 STL 算法。
- 偶数包括负偶数和 `0`。
- 不要求从标准输入读取，使用固定演示数据即可。

### 演示要求

对 `{1, 2, 3, 4, 5, 6}` 筛选偶数并求和。

基础验收输出：

```text
12
```

### 自测建议

- 没有偶数时输出 `0`。
- 包含负数。
- 尝试不创建中间 `evens` 容器，直接累加。

## 题 17：查找第一个大于平均值的元素

给定一组整数，找出第一个大于平均值的元素。

### 功能要求

- 使用 `std::accumulate` 计算总和。
- 平均值使用浮点数，避免整数除法截断。
- 使用 `std::find_if` 查找第一个大于平均值的元素。
- 如果不存在这样的元素，程序可以不输出或输出明确提示；演示数据必须有结果。

### 演示要求

对 `{1, 3, 5, 7, 9}` 查找。

基础验收输出：

```text
7
```

### 自测建议

- 空数组时不要除以 `0`。
- 所有元素相同。
- 第一个元素就大于平均值。

## 题 18：按出现频率排序

给定一批整数，按出现次数排序输出。

### 功能要求

- 统计每个整数出现次数。
- 按次数从高到低排序。
- 次数相同时按数字从小到大排序。
- 每行输出格式为 `number: count`。

### 演示要求

对 `{3, 1, 2, 3, 2, 3, 1}` 统计排序。

基础验收输出：

```text
3: 3
1: 2
2: 2
```

### 自测建议

- 全部数字出现次数相同。
- 包含负数。
- 只有一个数字。
