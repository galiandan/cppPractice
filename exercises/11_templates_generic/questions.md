# 十一、模板与泛型编程

本章目标：写能复用在多种类型上的函数和类，同时理解模板约束来自“被使用的操作”。

## 题 38：函数模板求最大值

实现一个 `maxValue` 函数模板，支持 `int`、`double`、`std::string` 等可比较类型。

### 功能要求

- 接收两个同类型参数。
- 返回较大的值。
- 不修改输入参数。
- 类型只要支持 `<` 比较即可使用。

### 演示要求

基础验收输出：

```text
7
2.5
stl
```

### 自测建议

- 字符串比较是字典序。
- 使用自定义类型，并提供 `operator<`。
- 思考返回值应按值返回还是按引用返回。

## 题 39：类模板栈

实现一个 `Stack<T>` 类模板，内部使用 `std::vector<T>`。

### 功能要求

- 支持 `push(value)`。
- 支持 `pop()`，移除栈顶元素。
- 支持 `top()`，访问栈顶元素。
- 支持 `empty()` 判断是否为空。
- 对空栈调用 `pop()` 或 `top()` 时，应抛出 `std::out_of_range` 或采用明确错误策略。
- 提供必要的 `const` 版本接口。

### 演示要求

压入 `"first"` 和 `"second"`，依次输出并弹出。

基础验收输出：

```text
second
first
```

### 自测建议

- `Stack<int>` 和 `Stack<std::string>` 都能工作。
- 空栈访问路径。
- 移动只可移动类型，例如 `std::unique_ptr<int>`，作为进阶挑战。

## 题 40：泛型打印容器

实现一个函数模板 `printContainer`，可以打印多种容器。

### 功能要求

- 支持能被范围 `for` 遍历的容器。
- 容器元素必须能输出到 `std::ostream`。
- 元素之间用空格分隔。
- 每个容器打印完成后换行。
- 至少能打印 `std::vector<int>` 和 `std::list<std::string>`。

### 演示要求

基础验收输出：

```text
1 2 3
hello cpp
```

### 自测建议

- 空容器。
- 单元素容器。
- 避免最后一个元素后多余空格，或确保检查器能容忍行尾空格。

## 题 41：模板特化

实现一个 `TypeName<T>` 模板，默认返回 `"unknown"`，对 `int` 和 `std::string` 做特化。

### 功能要求

- 主模板返回 `"unknown"`。
- `TypeName<int>` 返回 `"int"`。
- `TypeName<std::string>` 返回 `"std::string"`。
- 可以使用静态成员函数 `name()`。

### 演示要求

基础验收输出：

```text
int
unknown
std::string
```

### 自测建议

- 对 `double` 应返回 `"unknown"`。
- 思考函数模板特化和类模板特化的语法区别。
