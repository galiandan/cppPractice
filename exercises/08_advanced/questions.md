# 八、进阶挑战题

本章目标：训练更接近真实代码的建模能力，包括比较器、多态所有权、更新逻辑和 C++ 对象模型陷阱。

## 题 21：自定义比较器管理对象

定义 `Product` 类，包含名称、价格、销量，并按照销售额排序。

### 功能要求

- `Product` 保存名称、价格、销量。
- 销售额等于 `price * soldCount`。
- 使用 `std::vector<Product>` 保存商品。
- 按销售额从高到低排序。
- 销售额相同时，可以保持原顺序，也可以按名称字典序排序；必须让比较器逻辑稳定、可解释。

### 演示要求

基础验收会检查输出中包含：

```text
Mouse revenue=9600
Keyboard revenue=6000
Monitor revenue=6000
```

### 自测建议

- 价格为小数。
- 销量为 `0`。
- 销售额相同的商品排序规则是否明确。

## 题 22：多态版日志系统

设计一个多态日志系统。

### 功能要求

- 抽象基类 `Logger` 提供 `virtual void log(const std::string&) = 0`。
- `Logger` 必须有虚析构函数。
- `ConsoleLogger` 把日志输出到控制台。
- `MemoryLogger` 把日志保存到 `std::vector<std::string>`。
- 使用 `std::unique_ptr<Logger>` 统一管理日志器。
- 不允许手动 `delete`。

### 演示要求

使用 `ConsoleLogger` 输出：

```text
program started
```

### 自测建议

- 用 `MemoryLogger` 保存多条日志，并提供只读访问函数。
- 把不同日志器放进 `std::vector<std::unique_ptr<Logger>>`。
- 思考 `log()` 是否应该是线程安全的，当前题目不要求实现。

## 题 23：排行榜

设计排行榜系统。

### 功能要求

- 玩家有名字和分数。
- 支持添加新玩家。
- 如果玩家已存在，更新该玩家分数，不新增重复记录。
- 输出前 `3` 名。
- 排名规则：分数高者靠前；分数相同名字字典序靠前。
- 玩家少于 3 人时输出全部玩家。

### 演示要求

基础验收输出：

```text
Tom 110
Alice 100
Bob 90
```

### 自测建议

- 更新已有玩家分数后排名变化。
- 多个玩家分数相同。
- 空排行榜。

## 题 24：对象切片问题

解释什么是对象切片，并写出避免对象切片的写法。

### 功能要求

- 用注释说明：把派生类对象按值赋给基类对象时，派生类特有部分会被切掉。
- 给出至少一种避免切片的写法，例如使用基类引用。
- 给出另一种拥有型写法，例如 `std::unique_ptr<Base>` 指向派生类对象。
- `Base` 应有虚析构函数。

### 演示要求

本题基础验收只要求编译运行通过，不要求输出。

### 自测建议

- 写一个虚函数，在按值传参和按引用传参时观察调用差异。
- 思考为什么 `std::vector<Base>` 存派生类对象会切片。
