# 十二、文件、流与简单序列化

本章目标：练习文件打开、读取、写入、简单文本格式和错误处理。文件题必须明确格式，不能默默依赖本机路径。

## 题 42：读取成绩文件

从文本文件读取学生姓名和分数，计算平均分。

### 功能要求

- 文件名使用 `scores.txt`。
- 每行格式为 `name score`，姓名中不含空格。
- 文件打开失败时输出错误信息并返回非零退出码。
- 忽略无法按格式读取的剩余内容即可，不要求复杂恢复。
- 如果没有有效成绩，可以不输出或输出明确提示；演示文件有有效成绩。

### 演示要求

检查脚本会创建：

```text
Alice 90
Bob 80
```

基础验收输出：

```text
85
```

### 自测建议

- 文件不存在。
- 空文件。
- 分数为 `0`。

## 题 43：保存任务列表

把任务列表保存到文本文件，再从文件恢复。

### 功能要求

- 定义 `Task`，至少包含编号、完成状态、标题。
- 实现保存函数，把任务列表写入文本文件。
- 实现加载函数，从文本文件恢复任务列表。
- 保存格式必须可逆，标题包含空格时也能恢复。
- 文件打开失败时要有明确错误策略。

### 演示要求

基础验收会检查输出中包含：

```text
1 0 learn file stream
2 1 write serializer
```

### 自测建议

- 标题包含多个空格。
- 空任务列表。
- 文件内容损坏时不应越界或崩溃。

## 题 44：CSV 简单解析

解析一行简单 CSV 文本，例如 `Alice,95,cpp`，返回字段列表。

### 功能要求

- 以逗号 `,` 分隔字段。
- 不要求处理引号、转义和嵌套逗号。
- 空字段应保留，例如 `a,,b` 解析为三个字段。
- 返回 `std::vector<std::string>`。

### 演示要求

解析：

```text
Alice,95,cpp
```

基础验收输出：

```text
Alice
95
cpp
```

### 自测建议

- 空字符串。
- 末尾逗号：`a,b,`。
- 连续逗号：`a,,b`。

## 题 45：配置文件读取

读取简单配置文件，每行格式为 `key=value`。

### 功能要求

- 文件名使用 `app.conf`。
- 忽略空行。
- 忽略以 `#` 开头的注释行。
- 每个有效配置行按第一个 `=` 分隔 key 和 value。
- 重复 key 可以让后面的值覆盖前面的值。
- 文件打开失败时要有明确错误策略。

### 演示要求

检查脚本会创建：

```text
# test
host=127.0.0.1
port=8080
```

基础验收会检查输出中包含：

```text
host = 127.0.0.1
port = 8080
```

输出顺序不要求固定。

### 自测建议

- 行内包含多个 `=`。
- key 或 value 前后有空格，思考是否需要 trim；基础题不要求。
- 注释行前有空格时是否仍视为注释，基础题不要求。
