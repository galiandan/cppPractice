# 一、类与对象基础

本章目标：掌握类的封装、构造函数、成员函数、静态成员和基础输出格式。重点不是写复杂逻辑，而是把对象初始化到稳定状态，并让接口表达清楚。

## 题 1：学生成绩类

设计一个 `Student` 类，保存姓名、学号和三门课程成绩。

### 功能要求

- 构造函数一次性初始化所有成员，不允许留下未初始化字段。
- 使用合适的类型保存三门成绩，例如 `std::array<double, 3>`。
- 提供 `average()`，返回三门课平均分。
- 提供 `print()`，输出姓名、学号和平均分。
- 不会修改对象状态的成员函数应声明为 `const`。

### 演示要求

在 `main()` 中创建：

```cpp
Student s("Alice", 1001, {90, 85, 92});
s.print();
```

基础验收输出：

```text
name: Alice, id: 1001, avg: 89
```

### 自测建议

- 三门成绩相同。
- 平均分不是整数。
- `print()` 不应改变学生对象。

## 题 2：银行账户类

设计 `BankAccount` 类，支持存款、取款、查询余额。

### 功能要求

- 构造函数接收账户名和初始余额，初始余额默认可以为 `0`。
- `deposit(amount)` 只接受正数金额，非法金额不能改变余额。
- `withdraw(amount)` 返回 `bool` 表示是否成功。
- 取款金额必须为正数，且不能超过余额。
- 提供 `balance()` 查询当前余额，查询函数应为 `const`。
- 余额字段必须保持私有，外部不能直接修改。

### 演示要求

在 `main()` 中执行：

```cpp
BankAccount account("Bob", 100);
account.deposit(50);
if (!account.withdraw(200)) {
    std::cout << "withdraw failed\n";
}
std::cout << account.balance() << '\n';
```

基础验收输出：

```text
withdraw failed
150
```

### 自测建议

- 存入 `0` 或负数。
- 取出刚好等于余额的金额。
- 取款失败后余额不变。

## 题 3：静态成员统计对象数量

设计 `Counter` 类，统计“创建过的对象总数”。每调用一次构造函数，计数加一。

### 功能要求

- 使用私有静态成员保存计数。
- 构造函数中递增计数。
- 提供静态成员函数 `count()` 返回当前计数。
- 本题统计的是创建次数，不要求在析构时减少。

### 演示要求

在 `main()` 中创建两个对象并输出计数：

```cpp
Counter a;
Counter b;
std::cout << Counter::count() << '\n';
```

基础验收输出：

```text
2
```

### 自测建议

- 在局部作用域中创建对象，确认离开作用域后创建总数不减少。
- 思考“当前存活对象数”和“累计创建对象数”的区别。
