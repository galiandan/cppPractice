# 十、现代 C++ 练习

本章目标：使用现代 C++ 表达所有权、可空结果、类型安全联合和移动语义。优先让类型系统帮你避免错误。

## 题 34：智能指针管理对象

使用 `std::unique_ptr` 管理一组多态对象，避免手动 `delete`。

### 功能要求

- 定义多态基类，例如 `Animal`，包含虚函数和虚析构函数。
- 派生类实现不同输出行为。
- 使用 `std::vector<std::unique_ptr<Base>>` 保存对象。
- 使用 `std::make_unique` 创建对象。
- 不允许出现手动 `new` 后忘记释放，推荐不写手动 `delete`。

### 演示要求

基础验收输出：

```text
dog bark
cat meow
```

### 自测建议

- 添加第三种派生类。
- 尝试复制 `std::unique_ptr`，理解为什么不能复制。
- 思考何时应使用 `std::shared_ptr`。

## 题 35：移动语义追踪

实现一个 `Buffer` 类，内部持有动态数组。

### 功能要求

- `Buffer` 构造时分配动态数组并初始化。
- 析构时释放数组。
- 禁止拷贝构造和拷贝赋值。
- 实现移动构造和移动赋值。
- 移动操作应声明 `noexcept`。
- 被移动后的对象应处于可析构、可赋值的有效状态。
- 移动赋值要处理自赋值。

### 演示要求

创建长度为 `3` 的 `Buffer`，设置第一个元素为 `42`，移动构造到另一个对象并输出新对象状态。

基础验收输出：

```text
3 42
```

### 自测建议

- 连续移动。
- 移动赋值给已有资源的对象。
- 自移动赋值不应崩溃，虽然实际代码中应避免。

## 题 36：`std::optional` 查询结果

实现一个函数，在学生列表中按姓名查找分数。找不到时返回空值，不使用特殊分数表示失败。

### 功能要求

- 使用 `std::optional<int>` 表示查询结果。
- 找到学生时返回分数。
- 找不到时返回 `std::nullopt`。
- 不使用 `-1`、`0` 等特殊分数表示失败。

### 演示要求

查找 `Alice`，基础验收输出：

```text
95
```

### 自测建议

- 查找不存在的学生。
- 学生分数为 `0` 时仍应表示“找到了”。
- 使用 `if (score)` 或 `score.has_value()` 判断。

## 题 37：`std::variant` 表达不同消息

使用 `std::variant` 表达文本消息、登录消息、退出消息，并用 `std::visit` 处理。

### 功能要求

- 定义至少三种消息类型，例如 `TextMessage`、`LoginMessage`、`LogoutMessage`。
- 使用 `std::variant` 保存任意一种消息。
- 使用 `std::visit` 分发处理逻辑。
- 不使用手写类型枚举加裸 `void*`。

### 演示要求

处理一个登录消息，基础验收输出：

```text
Alice login
```

### 自测建议

- 处理每一种消息类型。
- 把多个消息放进 `std::vector<Message>`。
- 使用 `if constexpr` 写 visitor。
