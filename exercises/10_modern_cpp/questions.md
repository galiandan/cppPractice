# 十、现代 C++ 练习

### 题 34：智能指针管理对象

使用 `std::unique_ptr` 管理一组多态对象，要求避免手动 `delete`。

### 题 35：移动语义追踪

实现一个 `Buffer` 类，内部持有动态数组。要求支持移动构造和移动赋值，禁止拷贝。

### 题 36：`std::optional` 查询结果

实现一个函数，在学生列表中按姓名查找分数。找不到时返回空值，不使用特殊分数表示失败。

### 题 37：`std::variant` 表达不同消息

使用 `std::variant` 表示文本消息、登录消息、退出消息，并用 `std::visit` 处理。
