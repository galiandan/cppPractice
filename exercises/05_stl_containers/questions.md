# 五、STL 容器练习

本章目标：根据需求选择合适容器，并理解容器顺序、去重、查找和插入删除的成本。优先使用标准容器的性质，而不是手写复杂循环。

## 题 12：统计单词出现次数

从标准输入读取一批以空白分隔的单词，统计每个单词出现次数，并按字典序输出。

### 功能要求

- 使用 `std::map<std::string, int>` 或等价方案保证输出按字典序排列。
- 输入直到 EOF 结束。
- 单词区分大小写，不要求去除标点。
- 每行输出格式为 `word: count`。

### 演示要求

输入：

```text
cpp stl cpp oop
```

基础验收输出：

```text
cpp: 2
oop: 1
stl: 1
```

### 自测建议

- 空输入。
- 重复出现同一个单词多次。
- 包含大小写不同的单词，例如 `Cpp` 和 `cpp`。

## 题 13：学生成绩排序

给定多个学生姓名和分数，按照指定规则排序输出。

### 功能要求

- 定义结构体或类保存 `name` 和 `score`。
- 按分数从高到低排序。
- 分数相同时按姓名字典序从小到大排序。
- 排序规则必须是严格弱序。

### 演示要求

使用下列数据：

```cpp
{{"Tom", 88}, {"Alice", 95}, {"Bob", 88}}
```

基础验收输出：

```text
Alice 95
Bob 88
Tom 88
```

### 自测建议

- 所有人分数相同。
- 姓名相同但分数不同。
- 输入顺序已经有序或完全逆序。

## 题 14：去重并保持升序

从标准输入读取整数，去除重复元素，并按升序输出。

### 功能要求

- 输入直到 EOF 结束。
- 可以使用 `std::set<int>`，也可以使用 `std::sort` + `std::unique`。
- 输出所有唯一数字，按升序排列。
- 数字之间用空格分隔，行尾允许有一个额外空格。

### 演示要求

输入：

```text
3 1 2 3 2
```

基础验收输出：

```text
1 2 3
```

### 自测建议

- 空输入。
- 全部元素相同。
- 包含负数。

## 题 15：最近访问记录

实现一个最近访问页面列表。

### 功能要求

- 使用 `std::list<std::string>` 保存页面访问顺序。
- 最近访问的页面在表头。
- 访问一个已存在页面时，先删除旧位置，再插入表头。
- 最多保存 `5` 条记录，超出后删除最旧记录。
- 提供 `visit(page)` 和 `print()` 等清晰接口。

### 演示要求

依次访问：

```text
cppreference
github
stackoverflow
github
```

基础验收输出：

```text
github
stackoverflow
cppreference
```

### 自测建议

- 连续访问同一个页面。
- 访问超过 5 个不同页面。
- 访问第 5 个旧页面后，它应被移动到表头而不是重复出现。
