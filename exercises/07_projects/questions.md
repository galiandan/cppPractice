# 七、综合项目题

本章目标：把类、容器、查找、排序和状态变更组合成小型程序。重点是让每个类有清楚职责，`main()` 只负责演示。

## 题 19：图书管理系统

实现一个简化图书管理系统。

### 功能要求

- `Book` 类保存书名、作者、ISBN、是否借出。
- `Book` 提供只读访问函数，例如 `title()`、`isbn()`、`borrowed()`。
- `Book::borrow()` 成功时把状态改为借出，已借出时返回 `false`。
- `Book::giveBack()` 成功时把状态改为未借出，未借出时返回 `false`。
- `Library` 使用 `std::vector<Book>` 保存书籍。
- `Library` 支持添加图书、按 ISBN 借书、按 ISBN 还书、按书名关键字搜索。
- 查找不到 ISBN 时，借书和还书应返回 `false`，不能崩溃。

### 演示要求

在 `main()` 中添加：

- `Effective C++ / Scott Meyers / 001`
- `C++ Primer / Lippman / 002`

借出 ISBN `001`，搜索标题关键字 `C++`，再归还 ISBN `001`。

基础验收会检查输出中包含：

```text
Effective C++
C++ Primer
```

### 自测建议

- 重复借同一本书，第二次应失败。
- 归还一本未借出的书，应失败。
- 搜索不存在的关键字不应输出错误数据。
- 思考是否允许重复 ISBN；如果不允许，`addBook` 应返回成功/失败。

## 题 20：任务管理器

实现一个命令行风格的任务管理器核心逻辑。

### 功能要求

- `Task` 包含编号、标题、优先级、完成状态。
- `TaskManager` 使用 STL 容器保存任务。
- 添加任务时自动生成递增编号。
- 支持完成任务、删除任务。
- 完成或删除不存在的编号时返回 `false`。
- 输出未完成任务时，按优先级从高到低排序；优先级相同按编号从小到大排序。
- 输出函数不应改变原始任务列表顺序，除非接口明确说明。

### 演示要求

在 `main()` 中添加：

- `review OOP`，优先级 `3`
- `practice STL`，优先级 `5`
- `write notes`，优先级 `1`

完成第一项任务，然后输出未完成任务。

基础验收会检查输出中包含：

```text
practice STL priority=5
write notes priority=1
```

### 自测建议

- 删除已完成和未完成任务。
- 输出空任务列表。
- 添加两个相同优先级任务，检查编号排序。
